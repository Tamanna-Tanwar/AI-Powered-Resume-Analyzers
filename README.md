AI-Powered Resume Analyzer and Job Matching System

📌 Project Overview

The AI-Powered Resume Analyzer and Job Matching System is a Python-based project that compares a candidate’s resume with a job description.

The system identifies technical skills, finds matching and missing skills, calculates a skill-match score, and uses Natural Language Processing (NLP) to measure the similarity between the resume and job description.

🎯 Objectives

* Analyze resume content.
* Identify technical skills.
* Compare resume skills with job requirements.
* Identify matching and missing skills.
* Calculate a compatibility score.
* Use TF-IDF and Cosine Similarity for text comparison.
* Generate a simple recommendation.

🛠️ Technologies Used

* Python
* Google Colab
* Scikit-learn
* Natural Language Processing
* TF-IDF
* Cosine Similarity

⚙️ Methodology

1. Resume text is provided.
2. Job description is provided.
3. Technical skills are detected.
4. Resume skills are compared with job requirements.
5. Matching and missing skills are identified.
6. A skill-match score is calculated.
7. TF-IDF converts text into numerical vectors.
8. Cosine Similarity measures textual similarity.
9. The scores are combined.
10. A final recommendation is generated.

📊 Scoring

The final score is calculated using:

Final Score = 60% Skill Match + 40% NLP Similarity

Score	Recommendation
80–100%	Strong Match
60–79%	Good Match
40–59%	Moderate Match
Below 40%	Needs Improvement
